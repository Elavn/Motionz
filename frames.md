# **Motionz Studio — Flashy Website Preloader Specification**

> **Purpose:** Comprehensive creative, visual, animation, sound, and technical specification for the Motionz Studio website preloader.

---

## **1\. Creative Objective**

The visitor should **not feel like they are waiting for a website to load**.

They should feel like they have opened the production notebook, viewfinder, storyboard, or creative mind of **Motionz Studio** — and, for roughly two seconds, everything comes alive.

The preloader should communicate:

* Photography  
* Filmmaking  
* Weddings  
* Events  
* Documentary  
* Drone / aerial work  
* Human emotion  
* Movement  
* Framing  
* Visual storytelling  
* Controlled chaos  
* Professionalism  
* Creative confidence

The intended reaction:

> **“These people don't just record moments. They see them differently.”**

---

# **2\. Core Creative Idea**

## **MOTION IS EVERYWHERE.**

A moment begins.

A camera notices it.

The camera moves.

The subject moves.

The frame changes.

The photographer follows.

The scene expands.

The camera leaves the ground.

The frame becomes insufficient.

Everything collapses into the Motionz identity.

### **Final thought**

> **WE CAPTURE MOTION.**

# **4\. Target Duration**

## **Recommended total duration**

**Approximately 1.8–2.3 seconds**

The supplied Freshman reference establishes a very fast discrete-frame approach. Motionz should retain that principle rather than turning the preloader into a long cinematic intro.

Recommended structure:

| Phase | Duration |
| ----- | ----- |
| Black / focus | 80 ms |
| Frames 01–04 | 400 ms |
| Frames 05–09 | 500 ms |
| Frames 10–14 | 500 ms |
| Frames 15–16 | 280 ms |
| Brand handoff | 250–450 ms |
| **Total** | **\~2.0–2.2 sec** |

### **Absolute maximum**

**3–4 seconds.**

Never trap the visitor behind the animation.

# **5\. Frame Count**

Use:

## **17 primary visual frames**

Plus:

* Initial black state  
* Final brand state  
* Homepage transition

The 17 frames should be treated as **animation poses**, not necessarily 17 independently animated scenes.

The illusion of motion comes from:

* pose changes  
* hard cuts  
* directional composition  
* scale changes  
* motion lines  
* flash frames  
* graphic overlays

---

# **6\. Global Visual Language**

The artwork should resemble a combination of:

* Director's storyboard  
* Photographer's sketchbook  
* Production notebook  
* Rough animation  
* Ink study  
* Marker drawing  
* Camera diagram  
* Viewfinder graphics  
* Editorial illustration

The desired character:

> **Rough \+ sophisticated**

> **Messy \+ intentional**

> **Playful \+ cinematic**

> **Handmade \+ premium**

---

# **7\. What It Must NOT Look Like**

Avoid:

* Generic corporate illustration  
* Stock photography  
* Children's cartoon art  
* Generic comic-book art  
* Overly polished 3D characters  
* Photorealistic renders  
* Random doodles  
* Flat iconography  
* Generic wedding invitation graphics  
* Generic SaaS-style illustrations  
* A literal service advertisement

This is an **identity experience**, not a service brochure.

# **9\. Illustration Construction**

Every frame must look as though it belongs to the same visual universe.

### **Primary strokes**

Heavy hand-drawn outlines.

### **Secondary strokes**

Medium construction lines.

### **Motion strokes**

Thin directional lines.

### **Annotation strokes**

Small handwritten production notes.

### **Technical graphics**

More geometric and precise:

* Focus boxes  
* Viewfinder corners  
* Crosshairs  
* Tracking points  
* Aperture rings  
* Altitude marks

The contrast is intentional:

> **Rough illustration \+ precise camera language.**

---

# **10\. Imperfection Rules**

The artwork should contain **controlled imperfection**.

Include:

* Uneven circles  
* Double-drawn outlines  
* Loose construction lines  
* Overlapping strokes  
* Imperfect perspective  
* Arrows that overshoot  
* Handwritten notes  
* Eraser-like marks  
* Lines extending outside objects

But the composition must remain deliberate.

### **Rule**

> **Messy artwork. Precise art direction.**

# **18\. Image Generation Workflow**

Do **not** immediately generate all 17 frames independently.

---

## **Phase 1 — Master Style**

Create one master artwork establishing:

* line language  
* stroke weight  
* human proportions  
* camera style  
* focus graphics  
* annotation style  
* palette  
* visual density  
* roughness

---

## **Phase 2 — Recurring Assets**

Create consistent references for:

* Photographer  
* Camera  
* Drone  
* Wedding subjects  
* Event crowd  
* Focus graphics  
* Frame graphics

---

## **Phase 3 — Generate Frames**

Each frame receives its own prompt describing:

* scene  
* subject  
* pose  
* motion  
* camera angle  
* crop  
* graphic elements  
* transition direction  
* color  
* composition

---

## **Phase 4 — Normalize**

Post-process all artwork to maintain:

* same canvas  
* same line weight  
* same palette  
* same contrast  
* same grain  
* same visual language

---

## **Phase 5 — Animate**

Only animate after the artwork is approved.

# **26\. Animation Implementation**

## **Recommended Strategy: Image Stack**

For Motionz, an image stack is preferable to generating a single giant video.

Advantages:

* Exact timing  
* Easy frame replacement  
* Easy art-direction changes  
* Easy debugging  
* Easy mobile alternatives  
* Easy experimentation

Conceptual implementation:

const frames \= \[...\];

let current \= 0;

function showFrame(index) {  
    frames.forEach((frame, i) \=\> {  
        frame.style.opacity \= i \=== index ? "1" : "0";  
    });  
}

For the actual implementation, use a deterministic timeline or `requestAnimationFrame` rather than an uncontrolled interval.

* No visible decoding stutter  
* No layout shift  
* No white flash  
* No blank-screen trap  
* Smooth frame switching  
* Optimized assets  
* Hero loading in parallel

Use:

* WebP/AVIF  
* Responsive sources  
* Explicit image dimensions  
* First-frame priority  
* Lazy/parallel loading strategy for later frames

# **40\. Non-Negotiable Design Principle**

The most important rule for the entire implementation:

> **Do not make the preloader look expensive. Make it feel authored.**

Expensive can look like:

* polished 3D  
* cinematic stock footage  
* glossy transitions  
* generic luxury branding

Authored looks like:

* someone made deliberate visual decisions  
* recurring visual language  
* recognizable hand  
* strange but intentional compositions  
* motion with personality  
* visual ideas that belong specifically to Motionz

The visitor should be able to see **one frame** without the logo and still suspect:

> **“This is Motionz.”**

That is the actual goal
